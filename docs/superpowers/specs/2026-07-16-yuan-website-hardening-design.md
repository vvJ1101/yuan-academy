# YUAN 官网全面优化设计

## 目标与范围

本次优化对象是本地 `/Users/vv/Documents/YUAN开发/yuan-website` 及服务器 `/var/www/yuan-website`。目标是在不改变官网核心视觉和业务内容的前提下，修复 SEO、404、安全、依赖、性能、无障碍、类型和工程质量问题，并建立可验证、可回滚的部署流程。

明确不包含：合作申请表单、第三方访问统计、内容管理系统，以及 YUAN Academy 的数据库、API、页面或权限改动。

## 方案选择

采用“分阶段完整修复”：高风险和高收益问题优先，每个阶段独立验证。相比只修紧急问题，该方案能覆盖已发现的维护与体验缺口；相比重建官网，该方案保留现有页面结构、内容数据和视觉设计，控制改动范围。

## 变更设计

### SEO 与导航正确性

- sitemap 只收录真实官网首页 `/`，删除旧 `/showroom/` 和旧登录地址。
- 404 页返回链接改为 `/`。
- 删除无效的 360 搜索验证占位符。
- 保留并校对 canonical、Open Graph、Twitter Card、Organization 结构化数据及 robots 文件。

### 安全与依赖

- 使用 npm 审计结果定位中危和高危依赖，只升级到与现有 Next.js 14 和 React 18 兼容的安全版本。
- 关闭 `X-Powered-By`。
- 在 Next.js 响应层加入适配当前静态官网的安全头，包括 MIME 嗅探防护、Referrer Policy、Permissions Policy、Frame 限制和内容安全策略。
- CSP 只允许官网实际使用的脚本、样式、图片和字体来源；构建与线上页面验证必须同时通过。

### 性能与客户端边界

- 保留导航、滚动状态和必要动画的客户端逻辑；静态内容尽量保持可服务端输出的边界。
- 动画统一响应 `prefers-reduced-motion`，避免低性能设备和减少动态效果用户被迫播放动画。
- 测量并压缩超大图片，保持展示尺寸和清晰度；不改变页面引用路径。
- 检查首页构建产物和资源体积，以修复前后的可复现指标验收。

### 无障碍与交互

- 移动菜单补充 `aria-expanded`、`aria-controls`、Escape 关闭和打开后的合理焦点处理。
- 保证按钮触控区域不小于 44px，并修正明显不足的文字对比度。
- 保留键盘可操作性和清晰的焦点样式。

### 类型与工程质量

- 为 PLUS 渠道数据定义明确类型，移除 `as any`。
- 增加 `lint`、`typecheck` 和基础自动化检查脚本。
- 增加覆盖首页、404、sitemap、metadata 与安全头的最小测试，不引入大型测试框架；优先使用 Node 内置测试能力或已有工具链。
- 为官网建立 `.gitignore`，排除依赖、构建产物、日志和 macOS 元数据。官网是否初始化独立 Git 仓库和远程仓库作为实施后的交付选择，不在代码修复阶段擅自创建远程仓库。

### 资源清理

- 删除全部 `._*` macOS 元数据文件。
- 生成“被源码引用的公开资源”清单。
- 重复和未引用资源先复制到项目外的带时间戳本地备份目录，再从 `public` 发布目录移除。
- 清理后重新构建；任何缺失资源或页面异常均从备份恢复。

## 数据流与外部影响

官网继续使用 `src/data/home.ts` 和静态资源作为内容来源。本次不新增用户输入、数据库写入、邮件、第三方统计或跨系统数据流。线上只替换 `yuan-website` 源码与构建产物并重启该 PM2 进程；不修改 Nginx 和 `yuan-academy`。

## 验证标准

1. 依赖安装、lint、类型检查、自动化测试和生产构建全部通过。
2. sitemap 只包含真实首页，404 返回 404 且“返回首页”可用。
3. 首页、robots、sitemap、分享 metadata 和结构化数据正确。
4. 安全头存在且 CSP 不阻断页面脚本、样式和图片。
5. 移动菜单可使用鼠标、触摸和键盘操作，并支持减少动态效果。
6. 清理后不存在 `._*`，页面引用资源无缺失，首要大图体积显著下降。
7. 线上官网主域名和 www 域名返回正常响应，Academy 登录页保持正常。

## 部署与回滚

部署前在服务器创建官网源码和 `.next` 的带时间戳备份。本地验证通过后同步必要源文件，在服务器安装锁定依赖并构建，成功后仅重启 `yuan-website`。若构建、启动、CSP 或页面检查任一失败，立即恢复备份并重启旧官网进程；学院系统始终不参与部署。
